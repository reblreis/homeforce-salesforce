# 🏡 HomeForce

HomeForce is a Salesforce application designed to simplify the management of property sales and rentals.

The project simulates a real estate platform similar to QuintoAndar, applying Salesforce best practices, Apex development, Lightning Web Components, Flow automation, and AI capabilities.

---

## 🚀 Technologies

- Salesforce Platform
- Apex
- Lightning Web Components
- Flow Builder
- SOQL
- SOSL
- Reports & Dashboards
- Git
- GitHub

---

## 📌 Features

- Property Management
- Property Search
- Scheduling Visits
- Purchase Offers
- Rental Management
- Sales Dashboard
- AI Assistant (Agentforce)
- Customer Support (Service Cloud)
